# 哈尔滨旅行地图基线

## 技术与视觉

- React 19.3 + Vite + AntV L7 + 高德地图 + `animal-island-ui`。
- 全屏高德底图，草色青主题；面板、按钮悬浮于地图上。
- 地点坐标采用 GCJ-02，并持久化到 `src/data/travel-data.json`。
- 景点图片存放在 `public/images/places/`，数据只引用本地路径。

## 顶部目的地

按顺序显示：哈尔滨、港珠澳、香港、青海敦煌、贵湘。城市数量由数据决定，超出宽度使用左右箭头滚动。城市按钮下显示日期；选中哈尔滨后，日期下显示“全部、DAY-1、DAY-2、DAY-3”。右下日期与当前城市日期一致。

## 哈尔滨地点

红专街早市、中央大街、索菲亚大教堂、防洪纪念馆、松花江铁路桥、巴洛克风情街、松花江索道、极地公园、东北虎林园、哈尔滨大剧院、哈工大、哈药六厂、龙塔、黑龙江博物馆、伏尔加庄园、冰雪大世界、澜亭水汇、瓦西里俄式西餐厅、裕昌食品（中央大街店）、哈尔滨站、太平机场、亚季酒店、全季酒店（哈尔滨中央大街人民广场店）。不要加入净月潭。

名称映射以数据为准，例如：巴洛克风情街对应中华巴洛克历史文化街区，松花江铁路桥对应滨洲铁路桥，哈工大对应哈尔滨工业大学，黑龙江博物馆对应黑龙江省博物馆，太平机场对应哈尔滨太平国际机场。

## DAY 顺序

- DAY-1：太平机场 → 亚季酒店 → 全季酒店（哈尔滨中央大街人民广场店）→ 哈工大 → 黑龙江博物馆 → 哈尔滨站 → 澜亭水汇。
- DAY-2：红专街早市 → 松花江索道 → 极地公园 → 哈尔滨大剧院 → 东北虎林园 → 松花江铁路桥 → 巴洛克风情街 → 防洪纪念馆 → 瓦西里俄式西餐厅 → 中央大街 → 索菲亚大教堂。
- DAY-3：伏尔加庄园 → 哈药六厂 → 龙塔。

不得把路线改成从机场或酒店向各地点放射。连接必须依照上述顺序逐段串联。

## 路线与区域

- 景点间路线使用高德原生 `AMap.Polyline`，采用细粗适中的虚线、`showDir: true` 与 `dirColor`，让方向箭头成为折线自身的一部分。
- DAY 区域是覆盖当天全部景点的块状多边形，不是狭长路线带。填充半透明、边框实线，不同 DAY 使用不同颜色。
- 区域必须覆盖其全部成员。远距离单点只在对应边角做局部圆角外扩，不得整体放大整个区域。
- 单日模式只显示所选 DAY；“全部”模式可同时显示所有 DAY。DAY 名牌只在日程可见时出现。

- 黑龙江博物馆：提前 7 天预约。
- 哈药六厂：提前 7 天预约。
- 索菲亚大教堂：20 元，提前 1 天预约。

- 东北虎林园：90 元，提前 1 天预约。

有预约要求的名称统一展示为 `景点名（提前 x 天约）`。价格使用结构化数值字段保存，并在详情面板展示。

## 验收清单

- 路线顺序与 DAY 成员顺序一致。
